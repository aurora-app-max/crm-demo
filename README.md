# Atelier CRM — démo

Démo d'un CRM sur mesure pour PME : tableau de bord, contacts (import/export CSV, historique des échanges), pipeline commercial en glisser-déposer, devis (calcul HT/TVA/TTC, aperçu imprimable) et relances.

- Next.js 16, React 19, TypeScript, Tailwind CSS 4
- Données fictives stockées dans le navigateur (localStorage) : aucune base de données à configurer
- Compte de démonstration : `demo@atelier-crm.fr` / `demo2026`

```bash
npm install
npm run dev
```
